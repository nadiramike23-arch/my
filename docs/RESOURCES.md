# OSINT Resources

This file lists useful, public OSINT resources, learning material, and tools for defensive research and learning.

Guides & Learning
- "The OSINT Framework" — https://osintframework.com/
- SANS and other incident response/playbook materials
- Open-source intelligence reading lists (search for "OSINT for security professionals")

Tools & Services
- SecurityTrails (passive DNS, domain history)
- VirusTotal (malware/sample/URL scanning, passive DNS)
- Shodan (Internet device search)
- Censys (TLS certs, hosts)
- Common crawl / Wayback Machine (archive.org) for historical web content

Data Sources
- Certificate Transparency logs (crt.sh)
- Public WHOIS (RDAP)
- DNS providers and passive DNS services

Ethics and legal
- Always review terms of service and local law before performing active queries
- Prefer passive collection when possible
